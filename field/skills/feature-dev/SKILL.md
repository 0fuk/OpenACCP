# /feature-dev — 通用功能开发流水线

你是这条功能的编排者与最终把关人:拆解、定档、冻结、派发、消化复核、诚实呈报。执行下放,判断留手里。
两条根本原则:**本 skill 零项目事实**(第 0 步探测项目制度,探到即服从,探不到用内置默认并向 owner 明说);**五阶段不等重**,但复核独立性、呈报诚实性、不可逆面不许降低的底线任何档位不省。

## 第 0 步 · 开场
- **0.1 提取任务**:功能 slug、已知约束、已给事实源。只给一个名词连「给谁用/解决什么」都推不出时,合并成一条问一次。
- **0.2 项目探测(Glob+读文件,禁猜)**:CLAUDE.md;编排制度文件(coordination/launchers/工单目录——有则沿用其术语与文件,本 skill 模板只作缺省);可用 skill(分层调度/设计/复核类,命中先加载);门禁与基线(**现在实跑一次记下数字**,它是阶段四「只增不减」的锚);设计规范;git 地形(主线/干净否/worktree 惯例)。探不到写「无,用内置默认」。
- **0.3 规模定档(按结构信号,不按行数)**:

| 信号 | S | M | L |
|---|---|---|---|
| 数据模型 | 不动 | 只加字段 | 新表/迁移 |
| 契约/接口 | 不动 | 少量新增 | 新契约面/多端共用 |
| 端数 | 单端单点 | 单端 | 前后端都动 |
| 用户可见面 | 页面内微扩 | 一个新页面/命令 | 新导航域 |
| 未知度 | 一眼可指 | 半天吃透 | 整块空白 |

规则:有一项达到更高档就整体按更高档;**资金/鉴权/删除/迁移/对外发布强制 ≥M,复核按 L**;拿不准先按高一档跑阶段一,允许降档一次并说明,升档是义务。
档位×阶段:S=阶段一二合并、一张卡、主循环可亲做、一个独立挑刺复核;M=标准跑、2-5 卡+依赖图、1-3 worker、独立复核+数字门槛;L=全量、正式冻结件+UI 图纸先审、多泳道严格隔离、复核线+错误输入用例+数字门槛全套、分批验收。

## 阶段一 · 调研
代码考古(相邻实现=活规范/模型契约/挂接入口/既有测试;派便宜侦察代理,你读结论)→事实源收集(引用带路径;文档与代码矛盾时代码=现状、文档=意图,矛盾进空白清单)→外部调研仅需要时且带来源→敏感数据只记「存在/在哪/形状」不复制。
产物:**事实包**(每条带路径)/ **空白清单**(谁能补)/ **最小决策包**:
```
## 决策包·<功能名>(N 题,每题有默认值)
Q1 <一句话问题>  A(默认)<选项>——<理由>  B <选项>——<理由>  代价与可逆性:<选错后果/何时还能反悔>
不回复:可逆项按默认先行并标注;不可逆项(⚠)必须等答复。
```
题数 ≤5,无开放式问题;等答复期间只做不依赖答案的活。
关卡:能答「挂在哪/动哪些模型/最像哪个既有实现/测试基线多少」才进阶段二。反模式:跳过考古写码。

## 阶段二 · 编排
冻结顺序:数据模型→契约(含错误形状)→关键口径(命名/单位/精度/权限判据)+**编号命名空间预分配**(迁移号/工单号由编排预分配,多 worker 并行不撞号)。实现期改冻结件=回本阶段走变更。
UI 功能先出可交互图纸,owner 看图定稿即验收基准,施工同图。
切卡:每卡单一交付物、可独立验收、允许改动面互不重叠(重叠=真依赖串行,否则并发)。依赖图只画真依赖,事件判定式推进,禁日历。模型分层:有 tiering 类 skill 先服从;否则侦察便宜、实现中档、挑刺复核舍得花。
关卡:契约未冻结不派实现卡;UI 图纸未过 owner 不派 UI 卡;验收门必须机器能判定。反模式:边实现边定契约。

## 阶段三 · 执行派发
工单自包含(worker 没有你的上下文):
```
# 工单 <ID>·<卡名>
基座:<分支>@<hash>;工作区:<独立 worktree/分支,禁碰主线>
目标 / 允许改动面(白名单)/ 禁区(含敏感数据禁令)/ 验收门(数字化)/ 上下文(绝对路径)
交付纪律:先 commit 后写交付信;超 30 分钟落进度件;时刻先 date 后落笔;做不到写做不到。
```
交付信:基线(分支@hash,基于基座)/改动面/门禁数字/自我声明证据/没做与降级/建议复核点。
隔离纪律:每 worker 独立 worktree;**禁 git stash(整仓共享一个栈,并行必互踩)**;**写前 `git status --short` 自核,树上出现陌生 modified 文件=并发污染信号,停手上报,禁顺手 checkout 清掉**;要证明测试会抓错,只用 `git show HEAD:<path>` 导出对比、单文件 checkout、或「改坏→红→复原→绿」。合并权归你。
进度=落盘产物;失败升级:同一卡失败 2 次回收工单升档重派。
关卡:无 commit 的交付信无效;改动面越界打回。反模式:工单靠「参考我们刚才聊的」。

## 阶段四 · 独立复核
独立性:复核者=新起代理,拿工单+交付信+代码库,不拿聊天记录;审证据不审声明(亲自 checkout、亲跑数字,对不上=P0);故意用错误输入验证会被拒绝(M 起硬要求,不可逆面不许省);数字门槛(基线只增不减/静态门禁零新增/契约断言/UI 与图纸逐要素);**同一规则多份抄写的清点**(契约/前端/后端/终局器/守卫各一份,少数一层=半拉修复);**动了被封印/被清单登记的源→连带重打**。
分级:P0 阻断/P1 修完才过/P2 可放行但落盘记「何时回头修」/P3 建议。P0/P1 打回→原 worker 返工→**复核者复验**。
关卡:零未决 P0/P1 才进阶段五。反模式:实现者自审充当复核。

## 阶段五 · 最终验收
验收材料:能点的产物+起法说明+数据链说明(真数据/占位)+截图。呈报三段式:做了什么(每条挂证据)/没做什么/已知限制与风险;禁无证据的「完成」。验收通过≠发布,扣机权在 owner——项目档案记有 owner 明示授权口径时按项目的。打回逐条转录归属到卡/阶段回炉,不辩解。
关卡:owner 明确点头才算通过。反模式:让 owner 读 diff 当验收。

## 通则
零编造/诚实降级;产物落盘可追溯(项目有制度目录用项目的,否则 `.claude/feature-dev/<日期>-<slug>/` 带阶段前缀);图纸/冻结契约即基准;生成物禁手改;**外部依赖要有信号判据**——等的是对方会话级信号(交回件/进度)不是心跳,写明信号到了触发哪张卡,等待期间推进不依赖它的卡;上下文吃紧先落盘;不许降低的底线:资金/鉴权/删除/迁移/发布一律 L 档复核。

## 收尾自检
档位定过且改档宣布过;事实包带路径、⚠决策等到答复;冻结件没被偷改、UI 同图;每卡 commit+交付信且数字被复核者亲跑;零未决 P0/P1、P2 记档;呈报三段式、发布扣机在 owner。
